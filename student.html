Inside the print

Your parts are hollow. A machine decides how hollow.

First, the machine

Filament

A plastic string on a spool, about as thick as a coffee stirrer. That is the entire raw material.

Nozzle

It melts the string at about 200°C and lays it down as a line the width of a pen stroke.

The catch

The nozzle only draws flat. Height comes from stacking one flat drawing on the next.

The printer only knows how to draw one line. 
Software decides where every line goes.

Grid

Fastest. Crosses itself twice a cell.

Triangle

Stiffer sideways. Triangles don't rack.

Honeycomb

Good strength per gram. Slow: constant turning.

Gyroid

Ghost = the next layer. It shifts every time. Equal in all directions.

First three draw the same shape every layer. Gyroid changes as it climbs. That's the real split.

Take two things with you

A printer can't make a shape. It stacks a thousand flat drawings. That stacker is a compiler.

Same weight, different part. Placement beats quantity — across the layer, and up the stack.

One white ring = one pass of plastic over the same spot.

Grid

2 passes at every junction

Fastest, same every layer

Reach for it when you have no reason not to

Triangle

3 passes at every junction

Fast, same every layer

Reach for it when the part gets pushed sideways

Honeycomb

1 pass everywhere. Nothing stacks.

Slow, same every layer

Reach for it when you want stiffness per gram

Gyroid

1 pass everywhere. Nothing stacks.

Medium, changes as it climbs

Reach for it when the load direction is unknown
